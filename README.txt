Roza Zərgərli — rəsmi sayt
==========================
index.html   — tam sayt (bütün fotolar faylın içindədir, əlavə heç nə lazım deyil)
photos/      — orijinal fotolar (ehtiyat üçün)

Yerləşdirmə: index.html faylını istənilən hostinqə (cPanel, Netlify, Vercel, GitHub Pages) qoymaq kifayətdir.
Öz domenində YouTube pleyer, Spotify/Apple Music pleyerlər və klip cover-ləri tam işləyir.

Yeniləmə üçün faylda axtarın:
- Konsertlər: <ul class="shows"> və data-shows="..." (geri sayım)
- Yeni klip: wkLrPWz6hgQ video ID-sini əvəz edin
- Tərcümələr: var I18N={...}
